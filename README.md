# 이천계단지기 공식 홈페이지

이천 빌라·상가 계단청소 전문업체 이천계단지기의 공식 웹사이트입니다.  
계단청소·유리청소·화장실청소를 정기 구독 서비스로 제공하며, 무료 방문견적과 1인 대표 직접 관리로 신뢰할 수 있는 청소 서비스를 운영합니다.

🌐 **사이트 주소:** [2000stair.kr](https://2000stair.kr)

---

## 서비스 소개

- **계단청소** — 빌라·상가 계단 정기 구독 청소 (먼지 제거, 물청소, 난간 청소)
- **유리청소** — 상가 유리창 및 공동현관 유리 청소
- **화장실청소** — 공용 화장실 정기 청소

## 특징

- 이천 전 지역 서비스 (빌라·상가 전문, 아파트 제외)
- 1인 대표가 직접 관리 — 하청 없음
- 친환경 수입 세정제 사용
- 무료 방문 견적
- 카카오톡 채널 청소 결과 보고

---

## 기술 스택

React 19 + Tailwind CSS 4 + Express 4 + tRPC 11 + MySQL
